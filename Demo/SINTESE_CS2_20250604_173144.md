## 4. Recomendações Específicas

2. **T-Side**:
   - A ramp control
   - Mid control takes
   - B apartments execution

#### Lineups Importantes
1. **Smokes essenciais**:
   - CT spawn smoke (from T spawn)
   - Jungle smoke
   - Window smoke
   - A stairs smoke

2. **Flashes básicos**:
   - A site flash over palace
   - B site flash from apps
   - Mid flash for window peek

#### Ângulos Cruciais
- Connector to mid window
- Jungle to stairs
- Palace to site
- B short angles

### b) Para o Lado

#### CT-Side
1. **Estratégias defensivas**:
   - Jogar mais passivo com crossfires
   - Utilizar off-angles depois de utilities
   - Manter uma âncora sólida em cada site

2. **Posições recomendadas**:
   - A: Ticket/Firebox combo
   - B: Van/Bench setup
   - Mid: Window/Connector control

3. **Utilities prioritárias**:
   - Molotov para A ramp/Palace
   - Smoke para mid/B apps
   - Flash defensiva para retakes

#### T-Side
1. **Estratégias ofensivas**:
   - Execuções rápidas com utilities
   - Split A através de ramp/palace
   - B rush com controle de apps

2. **Posições para entry**:
   - Pre-smoke CT/Jungle antes de sair da ramp
   - Clear ticket/firebox sistematicamente
   - Controle de mid para lurk

3. **Utilities prioritárias**:
   - Set completo de smokes para A
   - Molotov para clear common spots
   - Flashes coordenados para entry

### c) Para Economia

#### Rounds de Eco
- Priorizar stack em um site com pistols
- Comprar utilities mínimas (flash/smoke)
- Jogar juntos para trade kills

#### Prioridades de Compra
1. **CT**: Rifle > Kit > Kevlar > Utilities
2. **T**: Rifle > Kevlar > Utilities > Kit

#### Gestão de Utilities
- Nunca morrer com utilities não usadas
- Coordenar uso com time
- Salvar smokes para after-plant
